# Dice App

Dynamic 3D & Interactive Dice Roller App built with React 19, Vite, and Tailwind CSS.

## Features

- Interactive 3D/2D dice rolling experience
- High-performance UI powered by Vite and React 19
- Styled with Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm / npm / yarn

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Deployment

Deployable directly to [Vercel](https://vercel.com).
